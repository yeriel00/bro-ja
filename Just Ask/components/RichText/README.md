# RichText

Long-form copy for the legal pages and any WYSIWYG field, at the 720 measure.

**Status:** in review (Nov 20). Built on the interior-page canvas; markup and options may still change before sign-off.

- `h2` 26/34 ExtraBold, `h3` 20/30 Bold, 16 between blocks; numbered lists with lettered sub-lists; blue underlined links.
- "Last updated" line in small muted text.

**Responsive behavior** (fluid): Single column at 720 max; nothing switches.

**ACF fields:** `updated` (date), `body` (WYSIWYG).

**Files:** `components/RichText/style.css` (and foundations; see System map).
