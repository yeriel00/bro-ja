`hero-face-grid.webp` (2160 × 839) is the flattened face-and-silhouette banner from the homepage design. In code it is:

1. the starting layout the animated grid reproduces,
2. the still image shown under `prefers-reduced-motion`,
3. the fallback if the script doesn't run.

It isn't the animation source; that comes from `Portraits/`.
