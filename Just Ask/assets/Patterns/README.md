- **`brain-illustration-top.svg` is the current pattern.** It's a top-view brain, one ink (`#1F6FD1`), 700 × 869, and the one the designs use.
- **Where it's used:** behind the statistic grid and on both edges of the CTA band. On the CTA band the left brain shows its left hemisphere and the right brain its right; the navy fade covers the inner halves. Interior pages (Nov 19): page header top-right corner (tilted, ends inside the header), FeaturedResource corner (white), behind the Contact form (bottom-right), and a small whole brain in the Resource Library empty state.
- **Recoloring:** always recolor it in code with a CSS mask (`--ja-pattern-url`, ink `--ja-pattern-ink`): `pale-blue` at 70% on white, `white` at 75% on pale blue, `muted-navy` at 60% on navy; `graphic-accent` only for the small whole-brain spot illustration. Never place it at full strength behind body text.
- **Variety:** change crop, scale and rotation per placement so it never reads as the same piece repeated; one per section at most; never on repeated items (cards, list rows).
- **Retired:** `topographic-brain-01.svg` and `-02.svg` (side view) are kept for reference only and aren't used by any component.
