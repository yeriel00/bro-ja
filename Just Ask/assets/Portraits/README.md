There are 16 pairs: `portrait-NN.webp` (photo) and `portrait-NN-silhouette.webp` (hand-made silhouette in `graphic-silhouette`). They are 192 × 192, transparent and square-cropped, web versions of the masters in the Dropbox *Images/04 Portraits* folder.

- **Use:** they feed the hero face grid. Each pair is one ACF repeater row (photo + silhouette).
- **Adding people:** new portraits must match the set: square, transparent background, head-and-shoulders framing, and a hand-made silhouette in the same color.
- **Meaning:** the portraits are illustrative. Their placement must never imply diagnosis status.
